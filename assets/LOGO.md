# OpenDDPM icon

`logo.png` was generated with the built-in image generation tool for this project.
The build converts this source into the macOS icon sizes and AppIcon.icns.

Prompt:

> Create a polished macOS app icon for OpenDDPM, an open-source ultrawide monitor
> input and split-layout switcher. Single centered rounded-square icon, dark
> midnight navy background, stylized ultrawide monitor outline with two luminous
> panes split 75/25, electric cyan left pane and soft violet right pane, a small
> elegant crossing-arrow motif integrated beneath the panes suggesting input
> switching. Crisp geometric forms with restrained soft dimensional lighting,
> excellent silhouette legibility at 32px, premium independent Mac utility
> aesthetic. No letters, no text, no Dell logo, no watermark. Square composition,
> icon fills most of the image, plain surrounding transparent canvas. Return a
> single icon, not a presentation board.
