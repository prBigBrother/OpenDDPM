OpenDDPM 0.5.0

1. Drag OpenDDPM.app to Applications.
2. Open OpenDDPM. Look for the split-monitor icon in the menu bar.
3. Discover your monitor, select the cable used by this Mac (DP, HDMI, or
   Thunderbolt), and confirm it. Setup does not switch the display.
4. Apply or create presets in the configuration window or menu bar.
5. Open Hotkeys to record a global shortcut for each preset. Use Command,
   Control, or Option with a key. Escape cancels; Clear removes a binding.

No other monitor-control app is required. The native DDC/CI helper is included.
Requirements: macOS 13+, Apple Silicon or Intel, supported Dell monitor with
DDC/CI enabled. U4025QW is the hardware-validated model on Apple Silicon.
The Intel driver is compiled but has not been tested on physical Intel hardware.

This build is not Apple Developer ID signed or Apple notarized. On a downloaded copy,
macOS may block first launch. Attempt to open it, then use System Settings >
Privacy & Security > Open Anyway and confirm. Do not disable Gatekeeper.

Keep this Mac visible is enabled by default. Presets that exclude your confirmed
input and their hotkeys are blocked until you turn that setting off. Switching
back after hiding this Mac can require the monitor joystick or a separate
USB control connection. Shortcuts work while OpenDDPM is running; choose
Launch at login if you want them available after signing in.

Monitor controls include brightness, contrast, speaker volume, color and HDR
where supported by the selected connection. Brightness keys include NuPhy's
legacy F14/F15 commands. Enable Keyboard brightness in Monitor controls and
grant Accessibility access when macOS requests it. Preset hotkeys do not need
this permission. Pending monitor edits run sequentially without disabling the
other controls.

The separate Preset Remote window has been removed. All presets in the menu
opens the existing Presets page. Saved presets, hotkeys and input settings
are preserved when upgrading. Source and releases:
https://github.com/prBigBrother/OpenDDPM
