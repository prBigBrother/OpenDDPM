OpenDDPM 0.1.0

1. Drag OpenDDPM.app to Applications.
2. Install and start BetterDisplay 2.2 or newer: https://betterdisplay.pro
   The BetterDisplay CLI helper is already included in OpenDDPM.
   Enable CLI / notification integration in BetterDisplay if you disabled it.
3. Open OpenDDPM. Look for the split-monitor icon in the menu bar.
4. Discover your monitor, select the cable used by this Mac (DP, HDMI, or
   Thunderbolt), and confirm it. Setup does not switch the display.
5. Apply or create presets in the configuration window or menu bar.

Requirements: macOS 13+, Apple Silicon or Intel, supported Dell monitor with
DDC/CI enabled. U4025QW is the model validated for this first release.

This initial build is ad-hoc signed, not Apple notarized. On a downloaded copy,
macOS may block first launch. Attempt to open it, then use System Settings >
Privacy & Security > Open Anyway and confirm. Do not disable Gatekeeper.

Keep this Mac visible is enabled by default. Presets that exclude your confirmed
input are blocked until you turn that setting off. Switching back after hiding
this Mac can require the monitor joystick or a separate USB control connection.
